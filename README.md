# NetworkWalks – Week 3 Cybersecurity Practicals

## Password Cracking: John the Ripper (JTR) & NetworkWalks Tools

This repository documents my hands-on practical activities for **Week 3 of my Cybersecurity training with NetworkWalks**.

The exercises focused on understanding password security, password hashes, and how commonly used password-cracking techniques can be applied in controlled laboratory environments.

## Week 3 Practical Exercises

### 1. W3-PM1: Password Cracking with John the Ripper (JTR)

**Objective:** Gain practical experience using John the Ripper to recover passwords from password-protected files.

**Activities performed:**
- Installed and configured John the Ripper.
- Prepared a password-protected PDF for testing.
- Extracted the PDF password hash for analysis.
- Used John the Ripper to perform a password-cracking exercise.
- Successfully recovered the PDF password.

**Key Learning Outcomes:**
- Understanding password-protected files.
- Introduction to password hashes.
- Practical use of John the Ripper.
- Understanding how password-cracking tools test password candidates.

### 2. W3-PM2: Password Cracking with NetworkWalks Tools

**Objective:** Understand password hash generation and recovery using NetworkWalks tools.

**Activities performed:**
- Explored NetworkWalks practical tools, including the Hash Calculator.
- Generated hash values for password testing.
- Used wordlists to perform password-matching exercises.
- Compared generated hashes against wordlist entries.
- Successfully identified the matching password.

**Key Learning Outcomes:**
- Understanding hash generation.
- Introduction to hash analysis.
- Understanding wordlists and dictionary-based attacks.
- Learning how password candidates can be matched against hash values.
- Understanding the importance of strong and unique passwords.
